ChatGPT Graph Navigator

Token setup

The extension normally captures the ChatGPT access token automatically. Use this page only when automatic capture is unavailable or you need to replace the stored token.

Manual token configuration

  1. Open chatgpt.com and sign in.
  2. Open DevTools and inspect a ChatGPT network request.
  3. Copy the bearer token from the request's Authorization header.
  4. Paste the token below, test it, and save it.

The token is stored in Chrome extension storage on this browser profile. You can clear it later from the extension settings popup.
